# Session dashboard

Scripts live next to this file (the skill's base directory, shown when the skill loads). The dashboard is a private claude.ai Artifact; every invocation of this skill regenerates it and republishes it to the same URL.

1. Run `python3 <skill base dir>/build.py` — writes `~/.claude/dashboard/index.html` (self-contained page) and prints its path, stats and `artifact_url=<url or empty>` (read from `~/.claude/dashboard/artifact_url`).
2. Publish with the Artifact tool, `file_path` = that path:
   - `artifact_url` empty → first publish: `icon: "dashboard"`, `description: "Sesje Claude Code: zadania, uruchomione sesje, pamięć, wznawianie."`. Then save the returned URL: `echo '<url>' > ~/.claude/dashboard/artifact_url`.
   - `artifact_url` set → first `action: "read"` with `url` and `path: "index.html"` (saves to scratchpad, keeps the page out of context; required before updating an artifact from an earlier conversation), then publish with the same `file_path` and `url`, no `icon`. If the artifact no longer exists, do a first publish instead and overwrite the URL file.
   - Don't read the generated HTML into context (~700 KB, generated by this skill from the user's own transcripts).
3. Reply in one line: the artifact URL. Nothing else unless the user asked a question about their sessions.

Only if the user explicitly wants a local file elsewhere: `python3 <skill base dir>/build.py <out.html>` and skip publishing.

Data sources (read-only): `~/.claude/projects/*/*.jsonl` (transcripts), `~/.claude/sessions/*.json` (running sessions, liveness via `/proc/<pid>`), `~/.claude/projects/*/memory/project_*.md`.

Sections: tasks — sessions grouped into the feasibility → plan → implementation (→ review/smoke/retro) flow, linked by Jira keys in artifact names (`ANALIZA_WYKONALNOSCI/`, `IMPLEMENTATION_PLAN/`), the main Confluence page of a skill session and plan files read by later sessions; each stage shows produced files (name, location) and sessions. Then running sessions (busy/idle, last prompt, `claude --resume <id>`), memory entries (project_*.md + sessions that wrote/read them, newest writer highlighted, each with `claude --resume <id>`), full session list — text search, filter by invoked skill (Skill tool or slash command), running-only toggle.
